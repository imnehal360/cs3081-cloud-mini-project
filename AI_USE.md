# AI Usage Disclosure

## Tools Used
ChatGPT was used as a development assistant during this project.

## How AI Was Used
- Explaining knowledge distillation, Kubernetes, networking, and CI/CD concepts.
- Assisting with Python scripts, Docker configuration, Kubernetes manifests, and GitHub Actions workflows.
- Helping debug errors encountered during implementation.
- Supporting documentation and report preparation.

## Verification
AI-assisted code was tested through automated unit tests, CI workflows, model evaluation, Locust load testing, and NACL simulation.

## Model Training
The project uses the phi3.5 teacher model to generate command-parsing labels for sequence-level knowledge distillation. The Pythia-70M student models were fine-tuned using Google Colab.

## Responsibility
The student is responsible for validating the submitted implementation, measurements, and conclusions.
